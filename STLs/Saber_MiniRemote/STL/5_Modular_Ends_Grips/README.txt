Saber Mini Remote - modular ends and grips
==========================================
www.printed-droid.com

Mix-and-match parts for all Saber Mini Remote versions (1_ to 4_). They replace EmitterRing_Long and GripTube.
The LockRings stay as before (print 2x, one in front of each end). Same thread and size as the Lightsaber Remote Standard:
these heads also fit the Lightsaber Remote (and its 7_Ends_Standard parts fit here).

EMITTER (front, joystick side) - screws onto the emitter stub behind the LockRing
  SaberMiniRemote_EmitterHead_<Style>_Short.stl   18 mm shorter than EmitterRing_Long
  SaberMiniRemote_EmitterHead_<Style>_Long.stl    same length as EmitterRing_Long
      styles: Classic (flared collar, windows), Shroud (wide disc with holes), Crown (octagon, crenellated), Stepped (grooves, stepped lip)

GRIP (back, USB side) - GripBody + PommelHead replace the one-piece GripTube (same total length 92.9 mm)
  SaberMiniRemote_GripBody_Classic / _Grenade / _Ribs / _Panels   grip with internal thread (onto the shells) and male thread for the pommel
  SaberMiniRemote_PommelHead_Classic / _Grenade / _Facet / _Spool  closed pommel heads
  Same thread on both GripBody ends -> two GripBodies can be stacked for a longer grip.
  Unscrew the whole GripBody for USB charging, as before.

  SaberMiniRemote_LockRing.stl   same LockRing as in the version folders (spare)

PREVIEWS
  Preview_PrintParts.png     all parts as they go on the print bed, with heights

PRINTING (as exported, no supports - every outer overhang is 45 deg or less)
  - Emitter heads: thread opening down.  GripBody: internal thread down, male thread up.  Pommel heads: flat bottom down.
  - Threads: right-hand, pitch 2.5 mm.
