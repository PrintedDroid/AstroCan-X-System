Saber Mini Remote - modular ends and grips
==========================================
www.printed-droid.com

Mix-and-match parts for all Saber Mini Remote versions (1_ to 4_). They replace EmitterRing_Long and GripTube.
The LockRings stay as before (print 2x, one in front of each end).

EMITTER (front, joystick side) - screws onto the emitter stub behind the LockRing
  SaberMiniRemote_EmitterSleeve_Classic / _Ribs / _Flutes   12 mm ring, slides over the stub first
  SaberMiniRemote_EmitterHead_Classic    flared collar with windows (current look)
  SaberMiniRemote_EmitterHead_Shroud     slim neck, wide disc with a ring of holes
  SaberMiniRemote_EmitterHead_Crown      octagon with recessed panels, crenellated top
  SaberMiniRemote_EmitterHead_Stepped    smooth shaft with grooves, stepped lip
  The head clamps the sleeve against the LockRing. Length = EmitterRing_Long.

GRIP (back, USB side) - GripBody + PommelHead replace the one-piece GripTube (same total length 92.9 mm)
  SaberMiniRemote_GripBody_Classic       ring grooves (current look)
  SaberMiniRemote_GripBody_Grenade       staggered raised pads
  SaberMiniRemote_GripBody_Ribs          long raised ribs
  SaberMiniRemote_GripBody_Panels        raised panels
  SaberMiniRemote_PommelHead_Classic / _Grenade / _Facet / _Spool   screws onto the GripBody
  The GripBody has an internal thread (onto the shells, like the GripTube) and a male thread for the pommel head.
  Same thread on both ends -> two GripBodies can be stacked for a longer grip.
  Unscrew the whole GripBody for USB charging, as before.

PRINTING (as exported, no supports - every outer overhang is 45 deg or less)
  - Emitter heads: thread opening down.  GripBody: internal thread down, male thread up.
  - Pommel heads: flat bottom down.  Sleeves: either way.
  - Threads: right-hand, pitch 2.5 mm.
