AstroCan X - Lightsaber Remote
==============================
www.printed-droid.com

Pick ONE version folder - it contains all parts of that version, already in print orientation.

  1_Standard_PrintFlat      Ø42 hilt, control box, shells printed lying (split face down), length approx. 270 mm
  2_Standard_PrintVertical  same, shells printed standing (pommel down), split in two:
                            shells 198 mm high + screw-on EmitterTube; new emitter (inner 45 deg cone) and pommel
  3_LowBox_PrintFlat        control box 3 mm lower, shells printed lying
  4_LowBox_PrintVertical    control box 3 mm lower, printed standing (like 2)
  5_Slim_PrintFlat          Ø38 hilt, shells printed lying
  6_Slim_PrintVertical      Ø38 hilt, printed standing (like 2), shells 198 mm, total length approx. 264 mm
  7_Ends_Standard           modular emitter/pommel: head + sleeve, 4 heads x 3 sleeves each, fits 1_ to 4_
  8_Ends_Slim               the same for Slim (5_, 6_)
  9_Test                    thread test pieces

Grip alternatives: every version folder 1_ to 6_ also has FrontShell/BackShell _Grenade, _Ribs, _Panels
(pattern on back and sides of the control section, see Preview_Grips.png). Use them as a pair instead of the plain shells.

Each version folder contains:

  FrontShell / BackShell    the two hilt halves (all modules sit in the FrontShell)
  EmitterTube               only vertical versions: screws onto the shells, carries the emitter ring
  EmitterRing / PommelRing  screw-on end pieces (they also hold the shells together)
  BlindPlug                 plugs for unused side-button holes (1x3 / 1x4 strip)
  DowelPin                  print 4x - alignment pins between the shells
  Preview_Assembly.png      what it looks like assembled
  Preview_Section.png       cut view (modules holders, threads)
  Preview_PrintParts.png    all parts as they go on the print bed, with heights

Vertical versions: only the underside of the control box needs support. Use a brim for the standing shells.
Threads: right-hand, pitch 2.5 mm.
