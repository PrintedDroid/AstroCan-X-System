Lightsaber Remote - end parts, Slim d38
==================================================
www.printed-droid.com

Fits 5_ and 6_. At each end: LockRing against the shoulder, then screw on the end piece. Thread d35, pitch 2.5 (like Saber Mini Remote).
Same thread as Standard and Saber Mini (d35), outer size d38. Standard/Mini heads also screw on (just bigger).

FILES
  Saber_Slim_LockRing.stl                     flat versions: print 2x / standing versions: 1x (emitter end)
  Saber_Slim_LockRing_Cone.stl                standing versions only: pommel end (cone towards the shell)
  Saber_Slim_EmitterHead_<Style>_Short.stl    total length like before (+2 mm)
  Saber_Slim_EmitterHead_<Style>_Long.stl     18 mm longer (like the Saber Mini EmitterRing_Long)
      styles: Classic (flared collar, windows), Shroud (wide disc with holes), Crown (octagon, crenellated), Stepped (grooves, stepped lip)
  Saber_Slim_PommelHead_<Style>.stl           closed bottom - unscrew for USB charging
      styles: Classic (flutes), Grenade (V-rings), Facet (octagon with slots), Spool (wide knurled foot)
