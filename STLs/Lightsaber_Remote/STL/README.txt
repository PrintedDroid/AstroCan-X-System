AstroCan X - Lightsaber Remote
==============================
www.printed-droid.com

Pick ONE version folder - it contains all parts of that version, already in print orientation.

  1_Standard_PrintFlat      Ø42 hilt, control box, shells printed lying (split face down)
  2_Standard_PrintVertical  same, shells printed standing (pommel down), split above the controls + screw-on EmitterTube
  3_LowBox_PrintFlat        control box 3 mm lower, shells printed lying
  4_LowBox_PrintVertical    control box 3 mm lower, printed standing (like 2)
  5_Slim_PrintFlat          Ø38 hilt, shells printed lying
  6_Slim_PrintVertical      Ø38 hilt, printed standing (like 2)
  7_Ends_Standard           all emitter heads (short + long) and pommel heads for 1_ to 4_, LockRings
  8_Ends_Slim               the same for Slim (5_, 6_)
  9_Test                    old thread test pieces (old d41 thread - do not fit the current parts)

Ends (since 2026-10-17, like the Saber Mini Remote): thread d35, pitch 2.5 at both ends.
LockRing against the shoulder (holds the shells together), then screw on emitter head / pommel head.
Standard ends = Saber Mini Remote ends: heads and LockRings fit both remotes.

Grip alternatives: every version folder 1_ to 6_ also has FrontShell/BackShell _Grenade, _Ribs, _Panels
(pattern on back and sides of the control section, see Preview_Grips.png). Use them as a pair instead of the plain shells.

Each version folder contains:

  FrontShell / BackShell    the two hilt halves (all modules sit in the FrontShell)
  EmitterTube               only standing versions: screws onto the shells, carries the emitter end
  LockRing (+ _Cone)        lock rings (standing versions: Cone ring at the pommel end)
  EmitterHead / PommelHead  default end pieces (Classic) - more designs in 7_ / 8_
  BlindPlug                 plugs for unused side-button holes (1x3 / 1x4 strip)
  DowelPin                  flat versions: print 4x - alignment pins (standing versions have the pegs built in)
  Preview_*.png             assembly, section, front/back, print parts, grips

Standing versions: only the underside of the control box needs support. Use a brim for the standing shells.
Threads: right-hand, pitch 2.5 mm.
