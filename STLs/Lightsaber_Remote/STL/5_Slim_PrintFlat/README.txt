Lightsaber Remote - Slim PrintFlat
==================================================
www.printed-droid.com

Slim d38, printed lying.
Ends like the Saber Mini Remote: thread d35 (pitch 2.5) at both ends, LockRing against the shoulder, end piece screwed on.

FILES
-----
  Saber_Slim_FrontShell.stl            front half - all modules sit in here
  Saber_Slim_BackShell.stl             back half
  Saber_Slim_FrontShell/BackShell_Grenade / _Ribs / _Panels   grip alternatives (use as a pair, see Preview_Grips.png)
  Saber_Slim_LockRing.stl              print 2x - lock rings, hold the shells together while an end is unscrewed
  Saber_Slim_EmitterHead_Classic_Short.stl   emitter (more designs, short and long: ../8_Ends_Slim)
  Saber_Slim_PommelHead_Classic.stl    pommel, closed - unscrew it for USB charging (more designs: ../8_Ends_Slim)
  Saber_Slim_BlindPlug.stl             plug for unused side-button holes (as needed)
  Saber_Slim_DowelPin.stl              alignment pin between the shells - print 4x

PREVIEWS
--------
  Preview_Assembly / Front / Back / Section / PrintParts / Grips

ASSEMBLY
--------
  1. Modules into the FrontShell, 4 dowel pins, close with the BackShell, 4x M2 countersunk screws.
  2. Screw a LockRing onto each stud up to the shoulder.
  3. Screw on pommel head and emitter head.

PRINTING
--------
  - Shells split face down; supports under the control box / openings as needed.
  - End parts (LockRing, heads) as exported, no supports. Threads: right-hand, pitch 2.5 mm.
