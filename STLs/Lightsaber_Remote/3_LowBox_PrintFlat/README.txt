Lightsaber Remote - LowBox, printed lying
=========================================
www.printed-droid.com

Like Standard, but the control box (and the front modules) sit 3 mm lower. Only the FrontShell differs.

FILES
-----
  Saber_LowBox_BackShell.stl                         back half (mounting cover)
  Saber_LowBox_BlindPlug.stl                         plug for unused side-button holes (as needed)
  Saber_LowBox_DowelPin.stl                          alignment pin between the shells - print 4x
  Saber_LowBox_EmitterRing.stl                       emitter ring, screws on top
  Saber_LowBox_FrontShell.stl                        front half - all modules sit in here
  Saber_LowBox_PommelRing.stl                        pommel ring with USB hole, screws on the bottom

GRIP ALTERNATIVES (optional - replace FrontShell + BackShell as a pair)
-----------------------------------------------------------------------
  Saber_LowBox_FrontShell_Grenade / Saber_LowBox_BackShell_Grenade   raised square pads (grenade grip)
  Saber_LowBox_FrontShell_Ribs    / Saber_LowBox_BackShell_Ribs      long raised ribs
  Saber_LowBox_FrontShell_Panels  / Saber_LowBox_BackShell_Panels    raised panels
  Patterns only on back and sides of the control section; control box, side buttons, switch, screws stay free.
  All pattern flanks 45 deg - prints like the plain shells, no extra supports.
  Preview_Grips.png shows all three (front and back).
