Lightsaber Remote - Slim, printed lying
=======================================
www.printed-droid.com

Ø38 hilt, length approx. 244 mm. Shells printed lying on the split face.

FILES
-----
  Saber_Slim_BackShell.stl                           back half (mounting cover)
  Saber_Slim_BlindPlug.stl                           plug for unused side-button holes (as needed)
  Saber_Slim_DowelPin.stl                            alignment pin between the shells - print 4x
  Saber_Slim_EmitterRing.stl                         emitter ring, screws on top
  Saber_Slim_FrontShell.stl                          front half - all modules sit in here
  Saber_Slim_PommelRing.stl                          pommel ring with USB hole, screws on the bottom

GRIP ALTERNATIVES (optional - replace FrontShell + BackShell as a pair)
-----------------------------------------------------------------------
  Saber_Slim_FrontShell_Grenade / Saber_Slim_BackShell_Grenade   raised square pads (grenade grip)
  Saber_Slim_FrontShell_Ribs    / Saber_Slim_BackShell_Ribs      long raised ribs
  Saber_Slim_FrontShell_Panels  / Saber_Slim_BackShell_Panels    raised panels
  Patterns only on back and sides of the control section; control box, side buttons, switch, screws stay free.
  All pattern flanks 45 deg - prints like the plain shells, no extra supports.
  Preview_Grips.png shows all three (front and back).
