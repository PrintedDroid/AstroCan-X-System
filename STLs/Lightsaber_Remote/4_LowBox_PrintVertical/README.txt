Lightsaber Remote - LowBox, printed standing
============================================
www.printed-droid.com

Control box 3 mm lower, printed standing and split like 2_Standard_PrintVertical.

FILES
-----
  Saber_LowBox_Vertical_BackShell.stl                back half (mounting cover)
  Saber_LowBox_Vertical_BlindPlug.stl                plug for unused side-button holes (as needed)
  Saber_LowBox_Vertical_DowelPin.stl                 alignment pin between the shells - print 4x
  Saber_LowBox_Vertical_EmitterRing.stl              emitter ring, screws on top
  Saber_LowBox_Vertical_EmitterTube.stl              screws onto the shells (top), carries the emitter ring
  Saber_LowBox_Vertical_FrontShell.stl               front half - all modules sit in here
  Saber_LowBox_Vertical_PommelRing.stl               pommel ring with USB hole, screws on the bottom

GRIP ALTERNATIVES (optional - replace FrontShell + BackShell as a pair)
-----------------------------------------------------------------------
  Saber_LowBox_Vertical_FrontShell_Grenade / Saber_LowBox_Vertical_BackShell_Grenade   raised square pads (grenade grip)
  Saber_LowBox_Vertical_FrontShell_Ribs    / Saber_LowBox_Vertical_BackShell_Ribs      long raised ribs
  Saber_LowBox_Vertical_FrontShell_Panels  / Saber_LowBox_Vertical_BackShell_Panels    raised panels
  Patterns only on back and sides of the control section; control box, side buttons, switch, screws stay free.
  All pattern flanks 45 deg - prints like the plain shells, no extra supports.
  Preview_Grips.png shows all three (front and back).

NOTES
-----
  - All parts standing as exported.
  - Only the underside of the control box needs support.
  - Use a brim for the shells.
  - Hardware: 4x M2 countersunk screws approx. 12 mm, 4 dowel pins.
