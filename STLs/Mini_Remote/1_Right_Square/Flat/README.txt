Mini Remote - right hand, square, Flat
======================================
www.printed-droid.com

AstroCan X Mini Remote case, right-hand version, square lid edges, flat back: the top shell walls go all the way down, the bottom plate sits inside.

FILES
-----
  MiniRemote_R_BottomShell_Flat.stl                  bottom with rear joystick hole
  MiniRemote_R_BottomShell_Flat_NoJoystick.stl       bottom without rear joystick hole
  MiniRemote_R_NavCap.stl                            cap for the navigation button
  MiniRemote_R_TopShell_Flat.stl                     upper housing (lid with all openings)

NOTES
-----
  - TopShell: lid down on the bed.
  - BottomShell: floor down on the bed.
  - NavCap: head down.
  - Pick ONE BottomShell: with rear joystick hole or NoJoystick.
  - Hardware: 5x M2 countersunk screws (sides + USB end).
